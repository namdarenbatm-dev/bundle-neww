# باندلینگ ورژن ۶ — توسن تکنو

نسخه پایه PWA برای ادامه توسعه در GitHub.

## اجرا
این پروژه HTML/CSS/JavaScript ایستا است؛ برای اجرای محلی می‌توان از Live Server استفاده کرد یا آن را روی GitHub Pages منتشر کرد.

## امکانات
- صفحه مدیریت برای ورود ورودی‌ها و تولید بسته‌ها
- صفحه کارگزار با دو بخش «بسته‌های پیشنهادی مدیریت» و «پیشنهاد اقتصادی هوشمند»
- دریافت بودجه کارگزار و نمایش بسته‌های قابل خرید
- نمایش کسری بودجه لازم برای خرید بسته‌های بالاتر
- خروجی CSV، چاپ و نصب PWA

## توجه پیش از انتشار
قواعد مالی موتور در `engine.js` حفظ شده‌اند؛ با این حال، پیشنهادهای هوشمند از بین بسته‌های تولیدشده فعلی مرتب می‌شوند. قبل از استفاده عملیاتی، منطق اولویت‌بندی و پوشش همه ترکیب‌های قابل ارائه را با آزمون‌های کسب‌وکار بررسی کنید. بودجه کارگزار ظرفیت خرید است و منبع تأمین تخفیف نیست.
